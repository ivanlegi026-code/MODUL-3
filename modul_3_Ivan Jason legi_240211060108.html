2. Format Multimedia

Elemen multimedia (audio/video) disimpan dalam file media dengan berbagai format dan ekstensi, misalnya: .swf, .wav, .mp3, .mp4, .mpg, .wmv, .avi.

5. Contoh Audio HTML5

<audio controls>
  <source src="horse.ogg" type="audio/ogg">
  <source src="horse.mp3" type="audio/mpeg">
  Browser Anda tidak mendukung tag audio.
</audio>

6. Contoh Video HTML5

<video width="400" controls>
  <source src="mov_bbb.mp4" type="video/mp4">
  <source src="mov_bbb.ogg" type="video/ogg">
  Browser Anda tidak mendukung video.
</video>

7. Menampilkan Video YouTube

Cukup ambil video id dari YouTube, lalu sematkan memakai <iframe>.

<iframe width="420" height="315"
src="https://www.youtube.com/embed/tgbNymZ7vqY">
</iframe>

Tambahkan parameter pada URL untuk mengatur:

  • ?autoplay=1 - video otomatis diputar
  • ?playlist=ID&loop=1 - video diputar berulang
  • ?controls=0 - kontrol pemutar disembunyikan

8. HTML Geolocation API

Digunakan untuk mendapatkan posisi (koordinat) pengguna. Browser akan meminta izin terlebih dahulu.

function getLocation() {
  if (navigator.geolocation) {
    navigator.geolocation.getCurrentPosition(showPosition);
  } else {
    x.innerHTML = "Geolocation tidak didukung.";
  }
}
function showPosition(position) {
  x.innerHTML = "Latitude: " + position.coords.latitude +
  "<br>Longitude: " + position.coords.longitude;
}

9. HTML Drag and Drop API

Elemen diberi atribut draggable="true" agar bisa diseret ke elemen lain.

Geser saya
function allowDrop(ev){ ev.preventDefault(); }
function drag(ev){ ev.dataTransfer.setData("text", ev.target.id); }
function drop(ev){
  ev.preventDefault();
  var data = ev.dataTransfer.getData("text");
  ev.target.appendChild(document.getElementById(data));
}
